## Purpose

This file is a continuation brief for the already-created clickable prototype prompt. It does not replace the master prompt. It adds the meeting-specific product ideas Yakin repeatedly cared about, explains how much the current prompt already covers, and gives exact UI placement and click behavior for a follow-up prototype pass.

Use this when the first UI is already generated from the master prompt and the next builder prompt needs to say: "Keep the existing app, but add these meeting-driven feature details."

## Short Feedback

The existing prompt already covers the correct V1 skeleton: public pages, onboarding, dashboard, leads, import, campaign builder, AI campaign assistant, templates, unified inbox, analytics, settings, and admin.

What is missing or too light are the ideas that make the product feel like Yakin's actual vision:

- AI business memory that learns the user's company, offers, URLs, calendar links, and instructions.
- List-first lead management with ongoing sync from Google Sheets, Brilliant Directories, and REST APIs.
- Global sender account pool, then per-campaign sender assignment with human-like sending variation.
- Inbox reply routing: same sender replies back vs central human inbox handoff.
- BCC/forwarding tracking so replies outside the platform do not lose context.
- AI draft reply learning with approval counts and confidence-based automation by category.
- Timestamped event tracking per lead, per email, and per campaign.
- Conversion-aware analytics, not just opens/replies.
- AI weekly/monthly campaign improvement suggestions.
- Signal-based nurturing when external systems update tags like `signed_up` or `profile_incomplete`.
- White-label/Super SaaS readiness beyond just a logo picker.
- A single Documentation entry where Yakin can open the complete platform guide and review every workflow step.

### 4. Reply Routing Setup For Unified Inbox

- `S6 Connect sender email`
- `Settings -> Sender accounts`

UI content:

- Clicking "Copy BCC address" shows a copied toast.

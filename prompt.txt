=== BEGIN MASTER PROMPT ===

# ROLE & GOAL

You are a senior product designer and front-end engineer. Build a **clickable, multi-screen prototype** of a B2B SaaS web application called an **AI Outreach Platform** (working name: shown as the workspace brand, neutral — not your own brand).

The product helps directory owners, agencies, and business communities: import leads, build email outreach campaigns (manually or with an AI assistant), send controlled email sequences, manage all replies in one unified inbox, and track performance with analytics.

This is a **UI-only prototype for stakeholder review**. It must look like a finished, premium product, but it has **no backend and no real functionality**. Every interactive element must **navigate** to the correct screen so a reviewer can click through the entire journey. Use **realistic placeholder data everywhere** (real-sounding names, companies, emails, numbers, charts) so the product feels alive.

Optimize for: clarity of flow, professional density, and a confident demo. The desktop web layout is the priority (target 1440px wide); make it responsive enough not to break, but do not invest in mobile.

---

# HARD CONSTRAINTS (read carefully)

- **No real functionality.** No real authentication, no real email sending, no database, no API calls. Forms do not validate or persist — their submit/primary buttons simply navigate to the next screen.
- **Everything clickable routes somewhere.** Every button, link, sidebar item, table row, and tab must navigate to a real screen in this prototype (or open a modal that exists). No dead buttons. If an action would normally do work, it instead routes to the logical "next" or "result" screen.
- **Use placeholder/mock data**, hard-coded in the components. Charts can use a charting library with static data.
- **Consistency over novelty.** Reuse the same shell, components, and tokens on every screen.
- Build with **React + Tailwind CSS** (or the closest equivalent your environment supports). Use **client-side routing** so navigation is instant. Use **Tabler Icons** (or Lucide as a fallback) for all icons.

# DESIGN SYSTEM (mimic Twenty CRM — follow exactly)

The entire look must feel like the open-source CRM "Twenty". The defining traits: monochrome neutral base, a single indigo-blue accent, compact dense typography, hairline borders instead of shadows, small corner radii, and pill-shaped colorful tags.

## Typography
- **Font family:** `Inter`, sans-serif (load from Google Fonts). Apply globally.
- **Weights:** use only **400 (regular), 500 (medium), 600 (semibold)**. Never use 700+/heavy. Headings are semibold, not black.
- **Scale (compact):**
  - Body / base: **14px** (0.875rem)
  - Small / secondary / table cells: **13px**
  - Micro / captions / tag text: **11–12px**
  - Section heading: **16px** semibold
  - Page title: **20px** semibold
  - Large display (landing hero only): **40–56px** semibold
- **Color of text:** primary text `#333333`, secondary/muted `#666666`, disabled/placeholder `#999999`.
- Line-height comfortable but tight (~1.4). Letter-spacing default.

## Color tokens (use these exact values)
- **Accent / primary (indigo-blue):** `#3E63DD`
  - Accent hover (darker): `#3A56C5`
  - Accent pressed: `#3651B8`
  - Accent soft background (tints): `#EDF0FD` / `#DCE3FB`
- **Neutrals (grayscale):**
  - White / surfaces: `#FFFFFF`
  - App page background: `#FCFCFC`
  - Subtle panel background: `#F8F8F8`
  - Hover row / hover fill: `#F4F4F4`
  - Light border / divider: `#EBEBEB` (primary border color everywhere)
  - Mid border: `#E3E3E3`
  - Disabled border / faint: `#D6D6D6`
  - Icon / muted: `#999999`
  - Secondary text: `#666666`
  - Primary text: `#333333`
  - True dark (rare, e.g. sidebar text active): `#1A1A1A`
- **Semantic / status (used for tags, badges, charts — soft pastel bg + saturated text):**
  - Green / success / "interested": text `#2A7E3B`, bg `#E7F5EA`
  - Red / danger / "not interested" / errors: text `#C62A2F`, bg `#FCEBEC`
  - Amber / warning / "question": text `#9A6700`, bg `#FFF4D6`
  - Blue / info / "out of office": text `#3E63DD`, bg `#EDF0FD`
  - Purple: text `#7C3AED`, bg `#F2EBFE`
  - Gray / neutral / "manual review": text `#666666`, bg `#F1F1F1`
- **Dark mode:** not required for this prototype. Build **light mode only**. (If your tool auto-adds a theme toggle, leave it on light.)

## Shape, spacing, elevation
- **Border radius:** small. Inputs/buttons/cards/tags = **6px**; modals/large panels = **8px**; avatars = full circle. Nothing should look like a big rounded pill card.
- **Borders:** 1px solid `#EBEBEB` is the primary way to separate things. Tables, cards, inputs, sidebar — all separated by hairline borders, **not** heavy shadows.
- **Shadows:** almost none. Only a very subtle shadow on floating elements (dropdowns, modals, command menu): `0 8px 24px rgba(0,0,0,0.08)`. Cards and panels use borders, not shadows.
- **Density:** compact. Table rows ~40px tall. Buttons ~32–36px tall. Generous but not airy padding (12–16px inside cards, 8–12px inside cells). This is an information-dense pro tool, not a marketing site.
- **Focus states:** 2px accent ring (`#3E63DD` at low opacity) on focused inputs.

## Core components (define once, reuse everywhere)
- **Button — primary:** accent `#3E63DD` bg, white text, 6px radius, 500 weight, hover `#3A56C5`. Small (32px) and medium (36px) sizes.
- **Button — secondary:** white bg, 1px `#E3E3E3` border, `#333` text, hover bg `#F4F4F4`.
- **Button — ghost/tertiary:** transparent, `#666` text, hover bg `#F4F4F4`. Used for icon buttons and toolbar actions.
- **Button — danger:** red text/border variant for destructive actions.
- **Input / select / textarea:** white bg, 1px `#E3E3E3` border, 6px radius, 13–14px text, `#999` placeholder, accent focus ring. Compact height (~34px).
- **Tag / chip:** pill (full radius is OK *for tags only*), 11–12px text, soft pastel bg + saturated text from the semantic palette, optional tiny colored dot. Used for statuses, lead tags, reply classifications.
- **Avatar:** circular, initials on a soft colored bg, or a photo. 24px in tables, 32px in headers, 64px on profiles.
- **Card / panel:** white bg, 1px `#EBEBEB` border, 8px radius, optional header row with title + actions.
- **Stat card:** label (12px muted), big number (24px semibold `#333`), small delta line (e.g. "▲ 12% vs last week" in green/red).
- **Table:** header row (`#FCFCFC` bg, 12px uppercase-ish muted labels, sortable carets), dense body rows (40px, hover `#F4F4F4`, 1px bottom border), leftmost column often checkbox + avatar + name, inline-editable feel (cells look editable on hover). Right-aligned action menu (⋯) per row.
- **Tabs:** underline-style tabs (active tab = `#333` text + 2px accent underline; inactive = `#666`).
- **Modal / dialog:** centered, white, 8px radius, subtle shadow + dim backdrop, header with title + close (✕), body, footer with secondary + primary buttons.
- **Dropdown / menu:** white, hairline border, subtle shadow, 13px items, hover `#F4F4F4`.
- **Empty state:** centered icon (line style, muted), short title, one sentence, one primary button.
- **Toast/snackbar:** small bottom-left card (only show as a static example where relevant).
- **Segmented control & filter chips:** for table filters/view switches.

# NAVIGATION MAP (routes + where things go)

Public/onboarding:
- `/` Landing → buttons go to `/signup`, `/login`, `/pricing`

- `/onboarding/sender` → Continue → `/onboarding/domain`
- `/onboarding/domain` → Continue → `/onboarding/done`
- `/onboarding/done` → "Go to dashboard" → `/dashboard`

App (inside shell):
- `/dashboard` — hub; cards/links route into each area
- `/leads` → row click → `/leads/:id`; "Import leads" → `/leads/import` (modal)
- `/leads/import` (modal over `/leads`) → "Import" → back to `/leads` (with a success toast)
- `/leads/:id` — lead profile
- `/campaigns` → "New campaign" → `/campaigns/new`; row click → `/campaigns/:id` (optional detail, can reuse analytics)
- `/campaigns/new` — choose Manual vs AI
  - Manual: `/campaigns/new/setup` → `/campaigns/new/senders` → `/campaigns/new/template` → `/campaigns/new/sequence` → `/campaigns/new/preview` → "Launch" → `/campaigns/launched` (confirmation) → "View campaign" → `/dashboard` or `/analytics`

- `/templates` → "New template" or row click → `/templates/editor`
- `/inbox` → thread list item selects a thread in the same 3-pane screen
- `/analytics` — tabs switch sections in place
- `/settings` — tabs switch sections in place
- `/admin` — admin overview (extra)
